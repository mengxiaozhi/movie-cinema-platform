# 首頁 YouTube 輪播

首頁前十則依使用者提供的順序交錯播放「電影預告」與「商業客戶」：穿著PRADA的惡魔2、理膚寶水、奧德賽、統一布丁、玩具總動員5、UBER、蜘蛛人、TEMPO、惡靈古堡：爆發夜、金車滿福。原山湖圖片與 Blender 短片接在其後，素材來源位於 `src/data/home-videos.js`。

- YouTube 透過官方 IFrame Player API 與 `youtube-nocookie.com` 嵌入。只建立目前的播放器，不預載其餘九支。每支完整播畢才切換，奧德賽保留原網址的 1 秒起播設定；使用者仍可切換上一則／下一則、暫停與靜音。
- 預設靜音，尊重減少動態效果偏好。自動播放遭阻擋時等候使用者播放；不可嵌入或載入失敗時顯示原 YouTube 連結，自動輪播開啟時 8 秒後接續下一則。
- 影片由 YouTube 提供串流、字幕與相關政策；內建播放列使用官方 `controls=0` 隱藏，改由外層輪播按鈕播放／暫停、靜音及切換。沒有下載、重新上傳或移除平台標誌。影片是否持續可嵌入仍由頻道決定。
- 素材最多 16 則，後台可選 YouTube 類型及電影預告／商業客戶分類。YouTube 不使用圖片／直連影片的顯示秒數設定。
- `upgradeHome()` 只將已知原始兩則內容升級成含這十支影片的版本 2。本機讀取舊的公開文件及草稿時套用；不在讀取時寫入 Firestore，不覆蓋自訂首頁。版本 2 儲存後，管理員移除的素材不會自動重加。
- 這次只修改本機原始碼及部署設定，沒有寫入公開文件或發布正式網站。正式發布前需部署新版前端及 `firestore.rules`；舊規則僅允許八則及圖片／影片類型，無法保存新格式。Hosting 的 CSP 已在原始設定中加入必要 YouTube 腳本與 iframe 主機，未放寬其他來源。

規則測試需安裝 Java Runtime 並啟動 Firestore Emulator；未啟動時套件原有兩項規則測試會明確跳過。
