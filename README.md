## 2026-10-19 價目表

使用者提供的 `reference/cinema-price-list-2026-10-19.png` 為本次價格與廳數來源，共 32 間影城、333 廳，各廳暫名「第1廳～第N廳」。`src/data/price-list.js` 留存逐筆資料；每檔每廳每週定價為 11,000／14,000／18,500／21,000 元。投放天數含首尾，僅允許 7 天的倍數；總價為週價 × 檔數 × 天數 / 7，前台試算與本機服務使用相同函式。每日檔數庫存仍按投放的每一天保留。

升級既有 Local Storage 時一次性套用價目表，保留原委刊快照、影廳 ID、庫存與容量；不在新表中的原始展示影城停用但保留紀錄。管理員自行新增的影城保留原啟用狀態。未提供的座位數、放映規格、地址及座標標示待補，沒有假設 IMAX 等規格；缺少座標的影城仍能從列表選購。原始範例保留於 `legacy-cinemas.js`，僅供既有 ID、位置及受眾資料銜接，新售價全部採使用者價目表。

目前版本使用真正的 Firebase Google 登入，其餘業務流程在瀏覽器本機運作。不顯示展示模式標示，亦不需要 Blaze。

## 已啟用的服務

- Firebase Hosting：靜態 React 網站。
- Firebase Authentication：Google 登入。
- Cloud Firestore：公開首頁輪播與管理員草稿，使用 Spark 免費額度；只有指定已驗證 Google 最高管理員可寫入。
- Local Storage：影城、影廳、價格、容量、委刊及審核紀錄。不同裝置不會同步；清除網站資料會移除紀錄。
- 選取影片後先讀取片長、檔案大小、解析度及格式，於確認視窗顯示；確認提交才記錄素材及基本規格，審核頁也會顯示。影片不會上傳至雲端，同一次工作階段可預覽，重整後要重新選取檔案才能播放。
- 素材片長不設上限，格式須為 MP4／MOV 且不超過 500 MB；多檔仍為重複投放，不合併片長。審核不再要求小於 30 秒，排片表優先顯示素材實際片長，容量仍按檔數計算。選取、提交與審核通過時都檢查規格，缺少規格的舊素材必須重新選取；音訊、影格率、編碼及放映規格仍需人工審核。本機 metadata 不是未來正式後端的安全驗證，正式上傳後須伺服器重新解析。

最高管理員使用 `shiaufeng68@gmail.com` 的已驗證 Google 帳號。其他帳號初次登入為廣告主；最高管理員可在同一瀏覽器內對已登入過的帳號分派三階管理角色。這些本機角色只控制目前模擬流程，不能視為未來正式後端的安全授權。

## 執行與部署

1. `npm install`
2. 依 `.env.example` 設定本機 `.env.local` 的 Firebase 公開 SDK 設定。
3. `npm run dev`
4. `npm test`
5. `npm run build`
6. `firebase deploy --only hosting,auth,firestore:rules --project movie-cinema-20261015`

Google Provider 與 OAuth 應用程式名稱、支援信箱設定在 `firebase.json`。部署 Authentication 不會升級帳單方案。登入時 Google 帳號選擇、密碼及授權由使用者本人操作。

## Modern Web Guidance 更新（2026-11-16）

依 [GoogleChrome Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance) 更新前端：

- 共用彈窗、首頁預覽及素材確認使用原生 `<dialog>.showModal()`；瀏覽器負責焦點邊界、背景停用與關閉後焦點還原。`closedby` 不支援時，以指標座標檢查補上背景點擊關閉，須按下及放開都在外側，避免選字拖曳誤關閉。處理中的購物車及素材提交不可關閉。
- 對話框及 `::backdrop` 使用 `overscroll-behavior: contain`，不修改 `html/body` 的 overflow。未支援非溢位容器捲動阻擋的瀏覽器，仍保留原生 modal 的背景停用及焦點邊界；背景捲動阻擋為漸進增強。
- 共用欄位以明確的 label/id 關聯、原生驗證及 `:user-invalid` 提供互動後錯誤提示，同步 `aria-invalid` 與當下可見錯誤的 `aria-describedby`。提示先於欄位，錯誤訊息保留空間；每個可互動範圍使用一個延遲的 polite live region。
- 影廳卡片使用自身的 inline-size 容器查詢，在窄欄位堆疊文字與金額；搜尋區使用 `<search>`，鍵盤使用者可跳至主要標題。
- 首頁大圖在 HTML 預載並設定 high fetch priority，頁尾圖片採原生 lazy loading。Leaflet 地圖透過動態 import 在切換地圖模式時載入，載入期間顯示佔位區。

靜態 `legacy-scan src --json` 沒有命中；此掃描只涵蓋指引中具確定性規則的子集（約 20%），不代表完整前端稽核。

原始 Gemini 程式位於 `reference/code_artifact.tsx`。後續完整後端程式保留於 `functions/`，相關部署設定另存為 `firebase.backend.json`；目前不會部署該設定、Cloud Functions 或 Storage。Firestore 僅用於首頁內容；委刊流程仍在本機，未來正式啟用前仍需完整整合與安全測試。

## 地圖與首頁管理

- 桌面首頁將縣市、行政區及影城選單放在輪播左側，右側縮小顯示圖片與影片；投放日期及受眾標籤位於下方。手機改為地點篩選、輪播、投放條件的上下順序。左側三個選單以原生 `form` 屬性關聯下方搜尋表單，變更任一條件即更新結果，無須確認按鈕。
- 前台品牌為「亞加媒體通路」，Firebase 專案 ID 維持 `movie-cinema-20261015`。主要內容與按鈕採 16–20px，篩選標籤及輔助資訊至少 14px（影片授權與地圖來源標示除外）。
- 即時篩選保留目前焦點、捲動位置與列表／地圖模式，結果影城數透過 polite status 通知。日期不完整、非整週或超過上限時保留最後有效檔期，暫停新增清單；離開日期欄位後顯示錯誤，修正後即更新。只有有效日期或影城資料變更才重查版位，地點與標籤篩選不重查相同檔期。
- 地圖開啟滾輪縮放、滑鼠拖曳、雙擊放大及觸控縮放。程式繪製 SVG 圖釘，縣市配色固定，選取保留原色並顯示勾號；圖例依當前搜尋結果顯示。無需額外圖片檔或圖像服務。

- 探索影城提供列表／地圖切換；勾選影城即將本影城可購買的全部影廳各加入 1 檔，取消勾選移除同一日期範圍的全廳項目；其他日期不受影響。部分影廳被移除時顯示部分選取，再次全選保留既有檔數。
- 地圖使用 Leaflet 與 OpenStreetMap 標準圖磚，保留來源標示，不預載或離線下載；可用 `VITE_MAP_TILE_URL` 改接相容圖磚服務（切換供應商時須同步更新 attribution 與 CSP）。目前無付費地圖帳號或 Google Maps 帳單。OSM 為盡力提供服務，沒有 SLA；底圖失敗時仍可使用清單選取。
- 點標記或框選可見範圍影城可批次加入全廳。「查看影廳與檔期」定位到卡片操作列。未設定有效座標的影城仍列在清單，可於後台補緯經度。
- 最高管理員：管理後台 → 首頁管理。可設定 1–16 則素材、順序、類型、分類、網址、秒數、授權文字及啟用狀態，預覽後儲存草稿或發布。支援 HTTPS 圖片／影片直連及 YouTube，YouTube 影片完整播畢才切換。外部主機或頻道需允許嵌入，目前不提供檔案上傳。YouTube 新增清單與本機升級方式見 `docs/home-youtube.md`。
- `siteContent/home` 僅單筆公開讀取，`siteDrafts/home` 僅指定最高管理員讀寫；其他集合維持拒絕客戶端存取。Firebase 預設資料庫位於 asia-east1，未變更帳單方案。

影城廳數與週價依使用者提供的價目表。實際廳名、座位、放映規格及新增據點資料仍待業務補齊。

## 首頁素材與受眾篩選

- 首頁採用 image_gen 產生的暖光木質影廳背景，影片等比例放置在中央銀幕內。輪播高度依視窗調整，讓 16:9 桌面第一屏保留標題及完整篩選列。可使用左右箭頭、圓點、暫停及聲音控制；影片結束切換圖片，圖片停留 9 秒。預設靜音並尊重減少動態效果設定。
- 影片採用 Big Buck Bunny 官方開放電影預告，來源為 W3C 範例媒體，CC BY 3.0；畫面及 `public/media/credits.txt` 保留署名與授權來源。原 Gemini 影片連結回傳 403，未使用。
- `public/media/firefly-couple.png` 為使用者圖片經內建 image_gen 去背的透明 PNG。最終指示：保留黃色文字「越暗的地方你越亮」、人物、玻璃罐及螢火蟲，只移除深色背景。依核定設計保留於頁尾。首頁原文字「沉浸式觀影場域／讓每一次曝光，都有份量。」已刪除。
- 篩選區採暖象牙白、深墨綠與香檳金細線。縣市、行政區、影城、有效投放日期與受眾標籤變更後立即更新結果、委刊日期及估算金額。「清除條件」立即還原全部條件與結果。
- 受眾標籤透過彈窗搜尋、分類、複選，勾選與清除選擇立即生效，彈窗同步顯示符合影城數。「完成」及關閉按鈕只關閉彈窗，保留已生效的選擇；移除頁面標籤也立即更新。複選標籤採任一符合。
- 日期區間使用原生日期欄位，起訖各有可見標籤、邊框及 48px 操作高度，旁邊顯示週數與天數；欄位不足時依日期容器寬度改為上下排列。受眾入口顯示已選名稱與數量，未篩選時顯示「不限受眾」，選取的標籤可逐一移除或清除受眾；日期錯誤顯示在同組欄位內。

## 選購清單

影廳卡片預設加入 1 檔，加入後可原地取消。購物車以加減按鈕調整檔數，最低 1 檔；多檔移除需確認。相同影廳及相同日期不重複加入，紅色徽章顯示影廳筆數。成功通知顯示約 4 秒，滑鼠懸停、鍵盤停留或頁面隱藏時暫停倒數；modal 開啟時暫存，關閉後才顯示。卡片版位顯示目前本機核准紀錄的每日最大使用量及最少餘額，加入清單不占用庫存。

## 互動與訊息元件

右上方選購與會員入口統一為至少 48px 高的操作區。選購清單直接顯示影廳筆數，數字保留於按鈕內；會員登入使用明顯的淺色按鈕，登入後改為姓名、角色與會員專區入口，登出保留獨立操作。窄版將主要操作放在同一列，長姓名可縮略但保留完整的可及名稱；不載入外部大頭貼。載入登入狀態時顯示「連線中…」並暫停登入操作。

| 元件 | 使用情境 |
| --- | --- |
| Modal | 編輯表單、影城／影廳簡介、素材預檢、核准／駁回／取消委刊、會員權限變更及首頁發布。涉及委刊時顯示日期、檔數與金額；失敗保留輸入，處理中不可關閉。 |
| Popconfirm | 多檔或整批移除清單、啟用／停用影城影廳、刪除輪播草稿；桌面顯示在操作按鈕附近，手機改成底部確認區；預設焦點為保留，Escape 或點外側取消。單檔清單移除保持直接操作。 |
| Alert | 連線與操作失敗、無法套用搜尋條件、素材不符規格，以及尚未開通登入的持續狀態。錯誤不會自行消失，需關閉或修正問題。 |
| Toast | 加入／移除清單、儲存成功等短暫回饋，訊息也能從實際清單或資料狀態確認。使用非 light-dismiss 的原生 manual popover，不搶焦點。 |
| Tooltip | 購物車及影片控制的簡短說明；版位庫存以可點擊的說明按鈕補充。支援滑鼠、鍵盤及觸控，必要規則仍顯示在頁面上。 |

共用元件位於 `feedback.jsx`、`Confirmation.jsx` 與 `ui.jsx`。Tooltip 使用 `interestfor` 與 hint popover，僅在缺少原生支援時載入相容套件；定位優先用 CSS Anchor Positioning，缺少時以座標計算避開視窗邊界。Modal 內的 popconfirm 放入同一個 dialog，避免被原生背景停用影響。

## GSAP 過渡動畫

`src/motion.js` 統一管理首頁分區進場、輪播素材淡入、Alert、Modal、Popconfirm 及 Toast 的過渡，只動畫化透明度與位移／縮放。一般過渡為 160–240ms，首頁分區最多交錯 80ms；原生鍵盤焦點操作即時切換，減少動態效果偏好改為 100ms 淡入淡出，偏好變更會立即完成正在播放的動畫。元件卸載時清除 GSAP context 並還原原始行內樣式。

Modal 的關閉按鈕、Escape 與背景關閉請求，以及 Popconfirm 的按鈕與 Toast 的關閉，會完成短退場後才關閉原生浮層；表單送出等外部狀態卸載仍即時完成。Tooltip 以 CSS 淡入淡出並保留 `display`／`overlay` 離散過渡，缺少支援時原生 light-dismiss 即時關閉。篩選與價格更新保持即時，不移動正在閱讀的卡片。

## 影城／影廳簡介與受眾標籤

前台影城簡介與影廳介紹以彈窗顯示；照片使用 HTTPS 網址，未知座位與上映資訊保持待補。營運於「影城與影廳 → 簡介管理」維護介紹、交通、商圈、上映資訊來源日期與影廳設備。最高管理員及影城管理員可於「受眾標籤」新增、編輯、停用標籤，再指派影城；審核人員不可修改。既有標籤標示為推估且尚待驗證，不代表已接入售票或消費市場資料。

預留情報平台地點代碼、標籤代碼、來源、期間、更新日期及可信程度，目前無自動同步或 API 串接。所有這些業務資料沿用本機 localStorage，不跨裝置同步。價格、訂單及庫存不由簡介編輯端點改寫。
